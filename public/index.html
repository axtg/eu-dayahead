About EU day-ahead prices

Day-ahead electricity prices for 9 European markets. Add your supplier's markup and VAT to see what you actually pay, and plan heavy usage for the cheapest hours.

Two ways to use this: use this hosted instance directly (UI on this page, or call the API at dap.xadi.eu/api/...), or self-host from the open-source repository with your own ENTSOE API key.

How to use

  • VAT: defaults to the country's standard rate; change it if yours differs
  • Markup: your supplier's fee in euro cents per kWh
  • Copy API URL: gets the request behind the current chart

Integrations

  • TRMNL: Dutch day-ahead prices on an e-ink display

Built something with this API? Email dap@xadi.eu to get it listed here.

Data and API

Prices come from the ENTSOE Transparency Platform, with Stekker.app as a fallback. Prices for the next day usually appear after about 14:30 CET. The "API" button has the documentation, rate limits and usage terms.

Example Requests

# Get today's Dutch prices with Next Energy markup
curl "https://dap.xadi.eu/api/nl/today?markup=0.024&vat=0.21"
# Get German prices with auto VAT
curl "https://dap.xadi.eu/api/de/next24h?autoVat=true"

Base Endpoints

GET /api/{country}/today
Today's 24-hour prices
GET /api/{country}/next24h
Next 24 hours from now

Query Parameters

Parameter Type Description Example
markup decimal Fixed markup in EUR/kWh 0.024
vat decimal VAT as decimal (0.21 = 21%) 0.21
autoVat boolean Use country's default VAT true
roundTo integer Decimal places (default: 5) 3
interval enum 60M (default, hourly mean) or 15M (quarter-hour pass-through) 15M

Rate Limiting

  • Rate limit: 10 requests per second per IP (configurable)
  • Headers: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset; 429 includes Retry-After
  • Data updates: Prices for the next day usually appear after about 14:30 CET
  • Cache: Upstream prices are cached server-side; markup/VAT applied per request
